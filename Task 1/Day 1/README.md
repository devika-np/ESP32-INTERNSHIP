# ESP32 Internship – Day 1

## Objective
To set up the ESP32 development environment using Arduino IDE and verify the ESP32 board through a basic test.

## Tools and Hardware Used
- ESP32 development board
- Arduino IDE
- USB cable
- USB serial driver

## ESP32 Setup
The ESP32 board was connected to the computer using a USB cable. The required USB serial driver and ESP32 board support were installed in Arduino IDE.

## Blink Test
A test program was uploaded to the ESP32 successfully, and the ESP32 was verified through the Blink test.

## Serial Monitor
The Serial Monitor was used to observe messages from the ESP32 at a baud rate of 115200.

## ESP32 vs ESP8266
ESP32 was selected because it provides more GPIO pins and built-in Wi-Fi and Bluetooth connectivity. These features make ESP32 suitable for IoT and sensor-based applications.

## Result
The ESP32 development environment was successfully set up and the board was tested using Arduino IDE.
